# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

Please follow these guidelines when contributing:

* Describe your changes clearly.
* Report bugs with enough information to reproduce them.
* Submit improvements that are relevant to the project.
* Keep code and documentation clear and easy to understand.
* Be respectful and constructive when communicating with other contributors.

Thank you for contributing to the project!
